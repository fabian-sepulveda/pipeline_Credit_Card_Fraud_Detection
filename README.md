# pipeline_Credit_Card_Fraud_Detection
El objetivo del pipeline es habilitar la detección y monitoreo diario de fraude en transacciones con tarjeta, permitiendo a los equipos de riesgo y operaciones analizar tasas de fraude, montos comprometidos y patrones por segmento, asegurando calidad, trazabilidad y disponibilidad de los datos para la toma de decisiones.
