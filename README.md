# Fraud & Payments Monitoring Pipeline (Batch)

## Objective
Build a batch data pipeline to monitor fraud activity and support business decision-making in a fintech context.

## Stack
- PostgreSQL
- Python
- Airflow (next step)
- dbt (next step)
- Docker


## KPIs

| KPI            | Descripción                  | Decisión             |
| -------------- | ---------------------------- | -------------------- |
| fraud_rate     | % transacciones fraudulentas | Ajustar reglas       |
| fraud_amount   | Monto total fraudulento      | Impacto financiero   |
| tx_volume      | Nº transacciones             | Carga operativa      |
| alerts_count   | Nº alertas generadas         | Capacidad del equipo |
| top_merchants  | Comercios con más fraude     | Bloqueos             |
| data_freshness | Última transacción cargada   | SLA                  |
